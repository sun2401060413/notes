## 1. 成文与素材的分工

| 维度 | 素材盘（本地 `auto-driving`） | 此处（`docs/intelligent-transport/`） |
| --- | --- | --- |
| 内容 | 摘录、白皮书、方案、报告原文 | 归并、重组、有判断的知识 |
| 组织 | 按来源与话题堆放，允许重复与残缺 | 按 M/T/V/A/S/I 六域编号，一篇只讲一件事 |
| 忠实度 | 忠于原文，不做加工 | 允许取舍，不确定处标注 |
| 用途 | 查证、找原始出处 | 学习、检索、写方案 |

同一份素材常能支撑多个节点（路侧设备手册里有标定方法，标准文件里有工程约束），
因此这里不做"一篇素材对一个页面"的镜像，也不为素材建索引。
素材按自己的目录与全文搜索找，这里只留归并后的结论。

## 4. 新增一个专题

1. **登记**：在 [M1](01-framework.md) 确认或新增编号，避免同一件事写两处；
2. **成文**：定义与边界 → 原理 → 方法与方案对比 → 工程要点 → 常见误区 → 待补；
3. **挂钩**：至少写 2 条与相邻节点的交叉引用（如 T3 与 V2、S1）；
4. **留白**：末尾列"待补内容"，没想清楚的部分显式记下，不用空话填满；
5. **回填**：更新总览页的"已成文"表。

## 5. 写作规范

- 一段讲一个观点，先结论后论证；
- 表格用于**对比**（方案、指标、阈值），不用于堆信息；
- 数字必须带口径：均值还是 P95、统计窗口、样本量；
- 不确定写"待核实"，不编造标准与数据；
- 加粗写成 `**文字**`，内侧不要紧贴全角括号或引号——`**ESKF（误差状态卡尔曼滤波）**` 不渲染（Markdown 的 flanking 规则），
  应写成 `**ESKF 误差状态卡尔曼滤波**` 或 `**半持续调度 SPS**`；
- 行内公式用 `$...$`，独立公式用 `$$...$$`，公式里不写中文；
- 引用外部素材在正文点名（如"某省团雾治理方案"），不建素材目录；
- 中文与数字之间加空格，专有名词保留原文。

| 周期 | 做什么 |
