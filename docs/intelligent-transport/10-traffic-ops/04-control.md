    * 补入干线与匝道控制的适用条件。

> 监测解决"看得见"，管控解决"管得住"。信号与限速是最直接、最便宜、也最容易做错的干预手段。

## 1. 信号控制的基础量

| 参数 | 定义 | 工程取值 |
| --- | --- | --- |
| 周期 $C$ | 一个完整相位循环的时间 | 城市 60–120 s，干道可到 150 s |
| 绿信比 $\lambda_i$ | 某相位绿灯时长 / 周期 | 按流量比分配 |
| 饱和流率 $S$ | 绿灯期间单车道的最大通过率 | 典型 1800–2000 pcu/h/车道 |
| 流量比 $y_i$ | $q_i / S_i$ | 关键流量比 $Y=\sum y_{crit}$ |
| 损失时间 $L$ | 起动、清空等损失 | 每相位 3–5 s |

**韦伯斯特最优周期**：

\[
C_{opt} = \frac{1.5L + 5}{1 - Y}
\]

它给出的是"延误最小"的周期，不是"通行能力最大"。$Y$ 接近 1 时公式失效（过饱和），此时要用通行能力优先策略。

## 2. 三种控制策略的适用边界

| 策略 | 原理 | 适用 | 局限 |
| --- | --- | --- | --- |
| 定时控制 | 按历史流量编排配时方案 | 流量稳定、日变规律强 | 突发流量无响应 |
| 感应控制 | 检测器触发延长/跳过相位 | 车流随机、支路流量小 | 高饱和时效果有限 |
| 自适应控制 | 实时检测 + 在线优化 | 主干道、流量波动大 | 依赖检测精度、算法稳定 |

国内大量路口仍是定时 + 时段方案（早高峰/平峰/晚高峰/夜间），这是**现实，也是优化空间最大的地方**。

## 3. 干线协调与绿波

```text
路口A ──── 行程时间 t ────▶ 路口B ──── 行程时间 t ────▶ 路口C
 绿灯窗口需按偏移量(offset)错开，使车流连续通过 → 绿波带
```

| 概念 | 含义 | 要点 |
| --- | --- | --- |
| 偏移量 offset | 相邻路口绿灯起点的时间差 | 按平均行程时间设定 |
| 绿波带宽 | 车辆可连续通过的时间窗 | 越宽越宽容，但受周期与流量约束 |
| 双向协调 | 上下行都要绿波 | 行程时间不等时需折中，带宽通常减半 |
| 带宽优化 | MAXBAND/MULTIBAND 类方法 | 用整数规划求最大带宽 |

!!! warning "绿波不是越宽越好"
    绿波带宽与支路通行、行人过街、左转保护互相挤占。为了一条干道的带宽，
    往往牺牲相交道路 20–30% 的通行效率，需按路网整体评价。

## 4. 快速路/高速的管控手段

| 手段 | 机理 | 关键参数 |
| --- | --- | --- |
| 匝道控制（入口调节） | 限制进入主线流量，保护主线不崩溃 | ALINEA 反馈：$r(k)=r(k-1)+K_R[O_{target}-O(k-1)]$ |
| 可变限速（VSL） | 降低速度→提高通行稳定性、延缓崩溃 | 限速档位与流量-占有率关系 |
| 车道动态管控 | 开放应急车道、动态车道分配 | 需评估应急车道承载与救援通行 |
| 路径诱导 | 分流，均衡路网负荷 | 诱导信息的可信度与遵从率 |
| 汇入协同 | 车路协同辅助合流 | 需间隙检测与协同算法 |

**ALINEA 的工程要点**：$K_R$ 过大导致振荡，过小响应慢；目标占有率 $O_{target}$ 应取通行能力对应的临界占有率，
而不是"越小越好"。

## 5. 管控算法的演进

| 阶段 | 方法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 规则 | 时段方案、感应逻辑 | 可解释、稳定、易验收 | 难以全局最优 |
| 模型优化 | MILP、MPC、动态规划 | 有理论保证，可约束 | 依赖精确模型，算力与标定成本高 |
| 学习 | 强化学习、模仿学习 | 潜力大，能处理高维 | 训练昂贵、稳定性与可解释性差，落地少 |

**当前现实**：成熟项目仍是"规则/优化打底 + 局部智能增强"，纯 RL 信号控制多在示范区或仿真里。

## 6. 车路协同带来的增强

| 应用 | 依赖消息 | 效果 |
| --- | --- | --- |
| 信号灯倒计时/绿波引导（GLOSA） | SPAT + MAP | 减少怠速与急加速，提升舒适性 |
| 公交/应急车辆优先 | BSM + SPAT | 优先通行，减少对主线的扰动 |
| 车流到达预测 | BSM（车辆位置与速度） | 比检测器更早、更准地预测到达 |
| 协同自适应巡航 | BSM | 提高单车道的通行能力（理论上可提升 20%+，实测打折） |

!!! tip "GLOSA 的真实收益"
    理论上节油 10–15%，实测往往只有一半，原因：①只有部分车装 OBU；②驾驶员遵从率不高；
    ③建议速度与实际交通冲突。评估时要按**渗透率分层**测算，不要用满载假设。

## 7. 评价指标

| 维度 | 指标 | 说明 |
| --- | --- | --- |
| 效率 | 平均延误、停车次数、行程时间、通行量 | 延误是信号评价的通用货币 |
| 公平 | 各进口道延误差、支路等待时间 | 避免"干线畅通、支路堵死" |
| 稳定 | 饱和度、排队溢出次数 | 溢出会导致死锁 |
| 安全 | 冲突次数、闯红灯率、黄灯困境区冲突 | 与 T3 联动 |
| 协同 | 绿波带宽、优先请求响应率 | 车路协同专项 |

## 8. 常见误区

1. **只看主线**：把支路堵死，整体效益反而下降。
2. **周期越长越好**：周期过长导致支路等待不可接受，行人过街困难。
3. **过度依赖自适应**：检测器一旦不准，自适应方案可能比定时更差，必须留"回落到定时"的能力。
4. **忽略行人与非机动车**：很多路口的实际瓶颈是行人和右转交织。
5. **不标定饱和流率**：直接套 1800 pcu/h，遇到大车比例高的路段严重失真。
