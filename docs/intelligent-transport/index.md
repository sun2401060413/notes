## 三条使用路径

**① 学习**：`M1 框架` → `T1 交通流` → `T2 监测` → `T3 主动安全` → `V1/V2` → `A0` → `I 标准与产业`

**② 检索**：先看 [M1 第 4 节](00-meta/01-framework.md) 的 4 条跨域场景链
（团雾预警、路口冲突、重点车辆、干线绿波），按业务问题顺链找节点；或凭编号直达（如 `T3.2 速度管控`）。

**③ 写方案**：`T3 主动安全管控` + `I1 标准与规范` + 归档区的招投标案例，
按"依据—技术—案例"三段拼装；写作规范与新增专题的步骤见 [M3.1](00-meta/04-reading.md)。
