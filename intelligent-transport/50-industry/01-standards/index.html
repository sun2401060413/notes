    I1 标准与规范¶

    版本信息

    Created by SunZhu 2024-02-26 Version 1.2.0

    Last Update：2026-11-17 17:50

    • 分层梳理国标/行标/团标/国际标准的关系；
    • 补入车路协同与主动安全常用标准清单；
    • 给出方案里引用标准的写法。

    标准决定"能不能交付"：同一套方案，引错标准条款，验收就过不去。

    1. 五层标准体系¶

    层级 代号 发布主体 效力 典型用途
    国家标准 GB / GB/T 国家标准委 强制 / 推荐 安全、分级、试验方法等底线要求
    行业标准 JT/T（交通）、YD/T（通信）、QC/T（汽车） 各部委 推荐 公路机电、通信接口、车载终端
    地方标准 DB+行政区代码 省级市场监管部门 推荐（本区域内） 地方建设导则、设备接入规范
    团体标准 T/CSAE、T/ITS、T/CITSA 学会与产业联盟 自愿采用 新兴领域先行，往往快于国标
    国际标准 ISO、SAE、3GPP、ETSI、IEEE 国际组织 参考 / 出口必需 功能安全、通信协议、自动驾驶分级

    几条实际经验：

    • 团标先行、国标跟进是这个领域的常态。做方案时团标往往是最新的技术依据，但验收文件一般认国标与行标。
    • 代号不带 T 的是强制标准（如 GB 5768 道路交通标志和标线）。强制标准不能"参考执行"，必须逐条对应。
    • 通信类标准更新快（3GPP 每个 Release 一版），引用时必须带版本号，不能只写"符合 3GPP 标准"。

    2. 车路协同与运行管控常用标准¶

    标准号 名称要点 管什么
    GB/T 40429-2021 汽车驾驶自动化分级 L0–L5 的定义与要素，讨论"是不是 L3"的前提
    GB/T 41798-2022 智能网联汽车 自动驾驶功能场地试验方法及要求 场地测试的项目与判定
    GB/T 40861-2021 汽车信息安全通用技术要求 车端信息安全的技术基线
    GB/T 20851 系列 电子收费 专用短程通信 ETC 5.8 GHz 链路、设备与接口
    GB 5768 系列 道路交通标志和标线 限速、警告、指路的设置依据（强制）
    T/CSAE 53-2020 合作式智能运输系统 车用通信系统应用层及应用数据交互标准 BSM/RSI/RSM/SPAT 的消息内容与交互流程
    T/CSAE 157-2020 合作式智能运输系统 车路协同 路侧感知系统 路侧感知的性能指标与测试方法
    ISO 26262 道路车辆功能安全 ASIL 划分与开发流程
    ISO 21448 预期功能安全 SOTIF 能力不足导致的危害，与 26262 互补
    ISO/SAE 21434 道路车辆网络安全工程 威胁分析与信息安全流程
    3GPP TS 22.185 / 23.285 / 37.885 V2X 业务需求 / 架构 / 评估方法 LTE-V2X 与 NR-V2X 的系统设计依据

    标准号与年号要核对

    上表用于建立索引，引用前必须核对正式发布版本的年号与现行状态（是否被替代、是否有修改单）。 标准换版会导致条款号变化，方案里写"依据 GB/T XXXXX-20XX 第 X.X 条"比写"符合国标"可靠得多。

    3. 写方案时怎么引标准¶

    1. 功能要求落到条款：每条技术要求后面挂一个标准号与条款号，评审时才站得住。
    2. 区分强制与推荐：强制标准写成"应"，推荐标准写成"宜"，混用会被专家挑。
    3. 接口类写清版本：V2X 消息集、地图格式、视频协议都要带版本，否则集成时对不上。
    4. 地方标准优先于团标：同一地区既有地标又有团标时，验收通常认地标。
    5. 没有标准依据时明说：写"现行标准未覆盖，采用本项目企业标准/试验验证"，比硬套一个不相关的标准安全。
