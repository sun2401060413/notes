    阅读路径¶

    主线：M1 框架 → T1 交通流 → T2 监测 → T3 主动安全 → T4 管控与信号 → V1/V2 → A0 → I 标准与产业

    按问题查：M1 第 4 节 的四条跨域链路（团雾预警、路口冲突、重点车辆、干线绿波）， 从业务问题顺链找节点；也可凭编号直达，如 T3.2 速度管控。

    做方案：T3 主动安全管控 + I1 标准与规范 + 项目案例，按"依据—技术—案例"组织； 写作规范见 M3.1。
